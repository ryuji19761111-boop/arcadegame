How to test

使い方

  1. GitHub Pagesで公開したURLをAndroidのChromeで開く。
  2. 「通知を許可する」を押し、ブラウザの確認画面で許可する。
  3. 「テスト通知を送る」を押す。
  4. 通知が表示されたら、タップしてサイトに戻れることを確認する。
このデモはボタン操作で通知を表示するテスト版です。サーバーからのプッシュ配信や、サイトを閉じている間に自動で届く通知は含みません。
通知はブラウザと端末の設定に従います。いつでも端末側で無効にできます。

このサイトの通知を有効にする？

許可すると、テストボタンから端末の通知欄に通知を表示できます。通知は必要なときだけテストしてください。
